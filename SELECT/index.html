SELECT

A SELECT SQL utasítás segítségével egy ideiglenes, virtuális táblát tudunk létrehozni,amely csak a lekérés végig létezik.

Előkészület:

Hozzuk létre a következő adatbázist a XAMPP felületen:

					
CREATE DATABASE tanker
DEFAULT CHARACTER SET utf8
COLLATE utf8_hungarian_ci;

USE tanker;
 
CREATE TABLE szemelyek (
    az int NOT NULL PRIMARY KEY AUTO_INCREMENT,
    nev varchar(50),
    telepules varchar(50),
    cim varchar(50),
    belepes date
);

Példák:

1. Példa: Sorold fel a szolnoki személyeket! Írasd ki a személyek nevét, mint "Személy" és a települést, mint "Település". 

                    
SELECT nev AS "Személy", telepules AS "Település"
FROM szemelyek
WHERE telepules = "Szolnok";

Mindig egy mondatként gondoljunk a leképezésünkre.

Válogassuk le a személyek nevét (nev), mint "Személy", a települést (telepules), mint "Település" SELECT nev AS "Személy", telepules AS "Település"
a szemelyek táblából, FROM szemelyek
ahol a telepules "Szolnok". WHERE telepules = "Szolnok";

A virtuális táblában a mezőnevek: "Személy" és "Település".


2. Példa: Sorold fel a szolnoki vagy debreceni személyeket! Írasd ki a személyek nevét, mint "Személy" és a települést, mint "Település". 

                    
SELECT nev AS "Személy", telepules AS "Település"
FROM szemelyek
WHERE telepules = "Szolnok" OR telepules = "Debrecen";

Mindig egy mondatként gondoljunk a leképezésünkre.

Válogassuk le a személyek nevét (nev), mint "Személy", a települést (telepules), mint "Település" SELECT nev AS "Személy", telepules AS "Település"
a szemelyek táblából, FROM szemelyek
ahol a telepules "Szolnok" vagy a telepules "Debrecen". WHERE telepules = "Szolnok" OR telepules = "Debrecen";

A virtuális táblában a mezőnevek: "Személy" és "Település".


3. Példa: Sorold fel azokat a személyeket, akik 2006.01.01. után léptek be! Írasd ki a személyek nevét, mint "Személy" és a belépés időpontját, mint "Belépés időpontja". 

                    
SELECT nev AS "Személy", belepes AS "Belépés időpontja"
FROM szemelyek
WHERE belepes > "2006-01-01";

Mindig egy mondatként gondoljunk a leképezésünkre.

Figyeljünk a dátumra: 2006.01.01. helyett 2006-01-01!

Válogassuk le a személyek nevét (nev), mint "Személy", a belépések időpontját (belepes), mint "Belépés időpontja" SELECT nev AS "Személy", belepes AS "Belépés időpontja"
a szemelyek táblából, FROM szemelyek
ahol a belepes nagyobb, mint "2006-01-01". WHERE belepes > "2006-01-01";

A virtuális táblában a mezőnevek: "Személy" és "Belépés időpontja".


Feladatok:

1. Feladat: Sorold fel azokat a szolnoki személyeket, akik 2006.01.01. előtt léptek be. Írasd ki a személyek nevét, mint "Személy", a települést, mint "Település" és a belépések időpontját, mint "Belépés időpontja". 

                    
SELECT nev AS "Személy", telepules AS "Település", belepes AS "Belépés időpontja"
FROM szemelyek
WHERE telepules = "Szolnok" AND belepes < "2006-01-01";

Mindig egy mondatként gondoljunk a leképezésünkre.

Figyeljünk a dátumra: 2006.01.01. helyett 2006-01-01!

Válogassuk le a személyek nevét (nev), mint "Személy", a települést (telepules), mint "Település", a belépések időpontját (belepes), mint "Belépés időpontja" SELECT nev AS "Személy", telepules AS "Település", belepes AS "Belépés időpontja"
a szemelyek táblából, FROM szemelyek
ahol a telepules "Szolnok" és a belepes kisebb, mint "2006-01-01". WHERE telepules = "Szolnok" AND belepes < "2006-01-01";

A virtuális táblában a mezőnevek: "Személy", "Település" és "Belépés időpontja".


2. Feladat: Sorold fel azokat a személyeket, akik 2004.01.01. után de 2007.12.31. előtt léptek be. Írasd ki a személyek nevét, mint "Személy" és a belépések időpontját, mint "Belépés időpontja". 

                    
SELECT nev AS "Személy", belepes AS "Belépés időpontja"
FROM szemelyek
WHERE belepes > "2004-01-01" AND belepes < "2007-12-31";

Mindig egy mondatként gondoljunk a leképezésünkre.

Figyeljünk a dátumra: 2004.01.01. helyett 2004-01-01 és 2007.12.31. helyett 2007-12-31!

Válogassuk le a személyek nevét (nev), mint "Személy", a belépések időpontját (belepes), mint "Belépés időpontja" SELECT nev AS "Személy", belepes AS "Belépés időpontja"
a szemelyek táblából, FROM szemelyek
ahol a belepes nagyobb, mint "2004-01-01" és a belepes kisebb, mint "2007-12-31". WHERE belepes > "2004-01-01" AND belepes < "2007-12-31";

A virtuális táblában a mezőnevek: "Személy" és "Belépés időpontja".
